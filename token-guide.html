Getting connected

Get your Lunch Money
access token.

A token is a private code that lets Mizan read your balances. You'll make one in Lunch Money, then paste it into the calculator.

Using YNAB? You don't need a token. Connect with YNAB instead.

A Lunch Money token can change data as well as read it. Mizan only ever reads. Make a fresh token just for Mizan and keep it private, so you can switch it off afterwards without affecting anything else.

  1. Open the Developers page

    Sign in to Lunch Money in a new tab. Go to Settings → Developers, or use the direct link below.

    Open Lunch Money Developers↗ (opens in a new tab)

    If you have more than one budget, check you're in the one you want to use for zakat.

  2. Request a new token

    Make a new token just for Mizan, even if you already have one for another app. Give it a label such as Mizan, say what it's for (for example "zakat calculation"), and choose Request Access Token.

    Settings → Developers → Request Access Token

  3. Copy it, then paste it into Mizan

    Copy the whole token as soon as Lunch Money shows it. You only see it in full once. If Mizan is still open in another tab, switch back to it. Otherwise use the button below. Paste the token into Lunch Money access token and choose Connect my accounts.

    Open the calculator

    Paste only the token itself: no quotation marks, no spaces, and never your Lunch Money password.

  4. Switch the token off when you're done

    Once you have your estimate, go back to the Developers page and choose Revoke for the Mizan token. You'll make a new one next time.

If you get stuck

I can't find my token

An existing token may be hidden after you create it. Request a new one on the Developers page, and copy it while it's shown.

Mizan says the token doesn't work

Copy the full token again, without extra spaces or quotation marks. If it was revoked or belongs to a different budget, request a new one. Mizan clears the input each time you try to connect.

Can I try Mizan without a token?

Yes. On the calculator, choose Try sample numbers. You'll see the same steps with fictional accounts, and nothing to connect.
